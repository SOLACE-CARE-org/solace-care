# Avatar

Initials in a disc, for specialists, seekers and staff. Specialists may later upload a photo; seekers never show one.

**Consumer provides:** the full name (for `aria-label`) and two initials: family name then given name for Cameroonian names as written ("Ngo Ebode Clarisse" → NE).

- 56px: `title-sm`-style initials (display face, 20px, 700), on profile and record headers.
- 36px (`sl-avatar--sm`): body face 13px, in lists and tables.
- Green (`brand-tint-strong` / `brand-deep`) by default; pink (`track-pink-soft` / `track-pink-ink`) only beside cycle-tracking content.

Don't use a generic person icon when initials are known.
