# EmptyState

What a screen shows before it has anything in it. It says what will appear here and gives the one action that fills it.

**Consumer provides:** a 40px stroke icon, a title that states the fact ("No sessions yet"), one sentence on what will appear, and at most one primary action.

- Icon in an 88px `brand-tint` disc, `brand` stroke.
- Title: display face 22px; body: 15.5px `ink-muted`, max 320px wide.
- Centered in the space between the header and the nav.

Admin empty states (no open crisis alerts) use the same parts at the panel's width and may add a quiet link ("See closed alerts").

Don't write jokes or exclamation marks. Someone may arrive here on a hard day.
